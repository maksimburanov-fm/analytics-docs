# June churn aggregate checks

Дата запуска: 2026-07-03.

Источник подписок: `spark_dm.subscriptions_with_revenue`.

Определение churn:

- 1 строка = последний валидный subscription end пользователя в месяце;
- пользователь попадает в risk base только если `end_date + interval '7 day' <= current_date`;
- `churn_7d = 1`, если нет следующей валидной подписки в течение 7 дней после `end_date`;
- для июня на дату анализа полностью наблюдаемы окончания подписок до 2026-06-26 включительно.
