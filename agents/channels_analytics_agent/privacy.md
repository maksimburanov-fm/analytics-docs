# Политика конфиденциальности

Дата обновления: 19.06.2026

Настоящая политика описывает, как GPT-агент для аналитики отчётов Freedom Media обрабатывает данные пользователей при работе с API отчётов и справочниками.

## 1. Какие данные обрабатываются

Агент может обрабатывать:

* текстовые запросы пользователя в чате;
* параметры отчётов: даты, каналы, провайдеры, пакеты, типы устройств и другие фильтры;
* данные, возвращаемые отчётным API;
* публичные справочники каналов, провайдеров и пакетов из Google Sheets.

Агент не запрашивает у пользователя пароли, платёжные данные, персональные документы или другие чувствительные данные.

## 2. Для чего используются данные

Данные используются только для:

* выполнения аналитических запросов пользователя;
* обращения к отчётному API;
* подбора нужных идентификаторов из справочников;
* формирования аналитического ответа в чате.

Данные не используются для продажи, рекламы или передачи третьим лицам по инициативе автора GPT.

## 3. Передача данных внешним сервисам

Для выполнения запросов агент может обращаться к:

* API отчётов Freedom Media;
* публичным Google Sheets CSV-справочникам;
* сервисам OpenAI, через которые работает Custom GPT.

Обработка данных в ChatGPT также регулируется политиками и настройками OpenAI.

## 4. Хранение данных

Автор GPT не ведёт отдельную базу данных пользовательских запросов и не сохраняет результаты отчётов вне инфраструктуры ChatGPT и подключённых API.

API-ключи и токены не публикуются в документации, Git-репозитории или сообщениях пользователя. Токен отчётного API хранится только в настройках Action.

## 5. Ограничения

Пользователь не должен вводить в чат:

* реальные API-ключи;
* пароли;
* персональные данные клиентов;
* коммерчески чувствительные данные, если у него нет права их обрабатывать.

Если пользователь передаёт такие данные самостоятельно, он несёт ответственность за наличие законного основания на их обработку.
