# spark_bsns_vlt.msp_ref_subscriptions

## Назначение

Таблица содержит подписки пользователей OTT-сервиса. Используется для анализа жизненного цикла подписки: определения первой подписки пользователя, подсчета активных и новых подписок пользователей за период, расчета оттока, анализа продлений и сегментации подписок по типу, тарифу и провайдеру.

## Гранулярность

Одна строка = одна подписка пользователя за период `start_date` - `end_date`.

## Основные поля

| Поле | Тип | Описание | Использование в аналитике |
|------|-----|----------|---------------------------|
| phone | character varying(100) | Номер телефона пользователя. Персональные данные. | Не использовать в аналитических витринах и отчетах; не выводить в выборках и документации с данными. |
| username | character varying(100) | Для некоторых пользователей записывается дублируется номер телефона. | Поле не используется. |
| t_w_srcid | numeric | Технический идентификатор записи в источнике или загрузке. | Использовать для технической трассировки и дедупликации, если требуется сверка с источником. |
| status | character varying(100) | Статус подписки в источнике. В DWH данные не перезаписываются, поэтому это поле не обновляется и содержит не актуальную информацию. | Поле не используется.  |
| end_date | timestamp without time zone | Дата и время окончания подписки. | Расчет churn (`end_date` меньше даты анализа), длительности подписки и границ периода доступа. |
| provider_id | integer | Идентификатор провайдера подписки. | Группировка и связка с справочником провайдеров, если он доступен; анализ подписок по источнику подключения. |

| last_login_date | timestamp without time zone | Дата и время последнего входа пользователя. В DWH данные не перезаписываются, поэтому это поле не обновляется и содержит не актуальную информацию. | Анализ активности подписчиков, сегментация подписок по давности последнего входа.|
| type | character varying(100) | Тип подписки: `trial`, `promo`, `subscribe`, `purchase`, `renew`. | Сегментация подписок: льготный период, промо-подписка, первая платная подписка или покупка после перерыва, продление рекуррентом. |
| packet | character varying(500) | Название или описание тарифа. | Анализ подписок по тарифу, группировка продаж и продлений по продуктовой упаковке. |
| groups | character varying(1000) | ГруппаЮ которой принадлежит пользователь..| Сегментация подписок по группам доступа, пакетам контента или внутренним категориям источника. |
| price | double precision | Базовая стоимость пакета за 1 период (без учетка скидок). | Не использовать. |
| start_date | timestamp without time zone | Дата и время начала подписки. | Определение первой подписки пользователя, построение когорт, расчет периода действия подписки. |
| provider | character varying(1000) | Название провайдера или канала подключения подписки, например Freedom Media или SuperApp. | Сегментация подписок и выручки по источнику подключения. |
| value | double precision |  Общая стоимость . | Не использовать. |
| t_w_crdate | timestamp without time zone | Техническая дата создания записи в DWH. По умолчанию `CURRENT_TIMESTAMP`. | Контроль свежести и аудит загрузки записи в хранилище. |
| register_date | timestamp without time zone | Дата и время регистрации пользователя. | Анализ конверсии от регистрации к первой подписке, построение регистрационных когорт. |
| t_w_system_code | character varying(10) | Технический код системы-источника. | Фильтрация и контроль происхождения данных при объединении нескольких источников. |
| user_id | integer | Идентификатор пользователя. | Ключ для определения первой подписки, поиска следующей подписки, расчета продлений и churn на уровне пользователя. Не выводить как персональные данные в отчетах. |
| t_w_loaddate | date | Техническая дата загрузки записи в DWH. | Контроль партиций, свежести загрузки и инкрементального обновления. |
| t_w_loadid | numeric | Технический идентификатор загрузки. | Аудит ETL-загрузок, поиск записей конкретного запуска загрузочного процесса. |
| packet_id | integer | Идентификатор тарифа. | Группировка и связка с тарифным справочником; более стабильный ключ тарифа, чем текстовое поле `packet`. |

## Ключевые поля

- `user_id` - идентификатор пользователя для связывания подписок одного пользователя и расчета первой/следующей подписки.
- `start_date` - начало периода подписки; используется для сортировки подписок пользователя.
- `end_date` - конец периода подписки; используется для churn и поиска перерывов между подписками.
- `type` - бизнес-тип подписки для сегментации trial/promo/первой покупки/продления.
- `packet_id` - идентификатор тарифа.
- `provider_id` - идентификатор провайдера.
- `t_w_srcid` - технический идентификатор записи источника.

## Поля дат

- `start_date` - дата и время начала подписки.
- `end_date` - дата и время окончания подписки.
- `register_date` - дата и время регистрации пользователя. 
- `t_w_crdate` - техническая дата создания записи в DWH.
- `t_w_loaddate` - техническая дата загрузки записи в DWH.

## Возможный жизненный цикл подписки 

Пользователь оформил триал: 
- trial -> subscripe -> renew -> Пауза -> purchase -> promo

Пользователь оформил триал: 
- promo -> subscripe -> renew -> Пауза -> purchase -> promo

Пользователь оформил первую подписку за полную стоимость: 
- purchase -> renew -> Пауза -> purchase

Пользователи Freedom Telecom и All Line:
- subscripe -> renew
